# V4 chai demo — images to generate (23 needed + 1 optional)

*(Kept as written for the original project.)* Put every file in **`06_Edit/demo_chai_v4/assets/images_in/`** with the exact file name below (`.png` or `.jpg`).
I cut out the props myself with rembg, so you don't need transparent backgrounds.

## General rules for every image
- **No text, no letters, no numbers, no logos, no watermark** anywhere in the image.
- Photorealistic, soft studio light, rich colour, slight film grain, like a premium science-explainer still.

**Backgrounds (B):**
- Portrait **9:16**, the biggest size your tool gives (at least 1080x1920; 1440x2560 is better).
- **Keep the top 30% calm and empty.** The titles go there.
- No objects in the middle, because I place the props there.

**Props (P):**
- Square **1:1**, at least 1024x1024.
- **ONE object only**, whole, not cropped, centred, filling about 70% of the frame.
- Plain **flat light grey background (#D9D9D9)**, no shadow on the background, soft top light.
- Same camera angle as written in the prompt.
